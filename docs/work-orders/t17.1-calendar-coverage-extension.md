## Context

M0_PLAN T17 의 v1.0.0 은 **2024 단년 verified** 만 포함. M0_PLAN AC-D-04 "지난 3 년 검증" 충족을 위해 2021~2023 의 KRX 공식 휴장일 cross-check 가 필요. 또한 운영 안정성을 위해 2025~2027 의 future 캘린더도 미리 박아두어야 일배치 (T18) 의 영업일 계산이 가능.

ADR-0008 D2: KRX 영업일 캘린더가 영구 진실 source.
ADR-0007 §2.1 Fidelity: best-effort 데이터 ≠ verified 데이터. 캘린더는 후자.

### 검증 정책

- 각 휴장일은 **두 개 이상의 1차 자료**에서 cross-verified:
  1. 행정안전부 공휴일 고시 (관공서의공휴일에관한규정)
  2. KRX 정보데이터시스템 휴장일 조회 (https://open.krx.co.kr)
  3. (보조) pykrx 또는 KIND
- 임시공휴일·대체공휴일은 정부 고시 일자 기준.
- 반장(half-day) — 1998 폐지 이후 신규 도입 X (M2 ADR 결정 시까지).

### JSON schema 갱신

`shared/schemas/krx-calendar-v1.json` 의 schema 자체는 변경 없음 (additive only). 만약
필요 시:
- `closed_days[].source: "ministry" | "krx" | "both"` 추가 — verified evidence 명시.
- `coverage.verified_partial: bool` — partial verification 지원.
