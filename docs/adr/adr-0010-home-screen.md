# ADR-0010: 홈 화면 정체성 — Watchlist + 시장 통계 2단

| | |
|---|---|
| **Status** | ACCEPTED |
| **Date** | 2026-05-22 |
| **Deciders** | 사용자 |
| **Related** | `docs/CONCEPT.md §2.2 No Advice`, `§2.3 Active Inspection`, `docs/M0_PLAN.md T10, T35`, [[adr-0006-legal-review]], [[adr-0007-default-ui-rules]] |

## Context

홈 화면 (로그인 직후 진입 페이지) 는 Speculum 정체성의 가장 강한 진술. 8 기둥 §2.3 (Active Inspection) 는 "앱이 의제를 정하지 않음" 을 약속 — 그렇다면 무엇을 표시할 것인가?

Metis 검토 E1 의 핵심 발견:
- 빈 검색창 = 사용자 막막함 (사용성 ↓)
- "오늘의 종목" = 의제 설정 = §2.2 No Advice 위반
- "AI 추천" / "유망주" 위젯 = 자본시장법 회색지대 ([[adr-0006-legal-review]] D2)

§2.3 과 사용성의 trade-off 를 단단히 풀어야 함.

## Decision

### D1. 홈 화면 = Watchlist (있으면) + 시장 통계 (의제 없는 fact) 2단 구조

### D2. 각 영역의 구체 규칙

#### D2.1 Watchlist 영역 (상단)

- Watchlist 가 비어있으면 → "관심 종목을 추가하면 여기에 표시됩니다" placeholder + Screener 안내
- 폴더가 있으면 → 첫 폴더는 펼침 (default), 나머지는 접힘
- 각 종목 row 는 클릭 시 Stock Detail 로 이동
- 종목 row 의 표시 컬럼 = 종목명 / 종목코드 / 시장 / 종가 / PER / ROE (default), 사용자가 customize 가능 (M1+)
- 정렬 = 사용자가 추가한 순서 (또는 사용자가 명시적으로 정렬한 column)
- as-of 가 오늘이 아니면 → "과거 시점 데이터" banner ([[adr-0008-as-of-date]] D4.1)

#### D2.2 시장 통계 영역 (하단)

표시 항목 — 모두 의제 없는 fact:

| 항목 | 데이터 |
|---|---|
| KOSPI / KOSDAQ 지수 | 종가 + 등락률 |
| 거래대금 | 시장 전체 |
| 상승·하락 종목 수 | 시장 폭 (breadth) |
| (M1) 외인·기관 매매 동향 | 순매수/매도 금액 |
| (M1) 업종별 등락 히트맵 | 분포 표시 |

**금지된 표시:**
- ❌ "오늘의 상승률 TOP 10" (가치 시그널 — 추세 추종 유도)
- ❌ "거래대금 급증 종목" (가치 시그널)
- ❌ "기관 매수 집중 종목" (시그널 해석)
- ❌ "AI 분석 인기 종목" (절대 금지)

**M1+ 검토 — 신중히:**
- "오늘의 거래량 상위 30 종목" — 단순 fact 이지만 "관심 시그널" 해석 가능. 도입 시 ADR-0007 D5.2 의 랭킹 경계 재검토.

#### D2.3 빠른 진입 영역

- 단순 navigation. 4 뷰 각각 진입.
- 추천이 아닌 menu.

#### D2.4 가이드 link

- 신규 사용자 대상. "Speculum 은 어떤 도구인가" 의 1~2 분 read.
- 8 기둥 요약 + "추천하지 않는다" 강조 + 기본 사용법 (조건 입력 → 결과 보기).

### D3. 신규 사용자 — Watchlist 비어있을 때

```
┌──────────────────────────────────────────────────────────┐
│  관심 종목이 비어있습니다.                                │
│                                                          │
│  Speculum 은 종목을 추천하지 않습니다.                    │
│  대신 조건을 입력해 시장을 직접 살펴보세요.               │
│                                                          │
│  [ 종목 검색 → ]   [ Screener 시작 → ]                   │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

추천 종목 자리 → 명시적 사용자 행동 유도. §2.3 Active Inspection 의 implementation.

### D4. as-of date 와의 상호작용

- 시장 통계 영역의 데이터는 as-of 기준.
- Watchlist 표시 데이터도 as-of 기준.
- as-of 가 과거이면 시장 통계 영역에 banner "*과거 시점 (2024-10-01) 의 시장 통계 표시 중*".

### D5. 모바일 반응형

세로 1 컬럼:
1. Watchlist
2. 시장 통계 (지수 카드 stacking)
3. 빠른 진입

가이드 link 는 모바일에서 footer 로.

### D6. 첫 진입 (회원가입 직후) — Tour 옵션

신규 사용자 첫 진입 시 1 회 한정 가이드 tour (3 단계):

```
1. 헤더의 as-of picker 강조 → "모든 데이터는 이 날짜 기준입니다."
2. 좌측 메뉴 강조 → "Screener 로 조건 입력, Stock Detail 로 종목 조회"
3. 가이드 link 강조 → "더 자세한 사용법"
```

skip 가능. tour 완료 후 다시 표시 X.

### D7. 광고·홍보 영역 — 절대 없음

[[adr-0007-default-ui-rules]] D7 일관. 홈 화면에 외부 link / 제휴 / cross-sell X.

## Rationale

1. **§2.3 Active Inspection** — Watchlist 는 사용자가 정한 의제, 시장 통계는 의제 없는 fact. 시스템이 정한 의제 0.
2. **§2.2 No Advice** — 어떤 종목 추천 위젯도 없음.
3. **사용성 균형** — Metis E1 의 "빈 캔버스 vs 의제 설정" 사이의 단단한 위치. Watchlist (사용자 의제) + 시장 통계 (객관 fact) + 빠른 진입 (navigation).
4. **Tessera ADR 0024 (UI customization)** 패턴 — 시스템 default 가 사용자 자유를 침해하지 않는 형태.
5. **신규 사용자 안내** — 빈 Watchlist 상태에서 명시적 "Speculum 은 추천하지 않는다" 안내.

## Consequences

### Positive
- **사용자 시작점이 명확** — Watchlist (있으면) 가 의제. 첫 사용 시 가이드.
- **추천 위젯 자리 자체 없음** — 미래에 silent regression 어려움.
- **사용성 균형** — 빈 캔버스 도아니고 의제 설정도 아닌 중간점.
- **as-of 일관** — 홈 화면도 PIT 의 일부.

### Negative
- **신규 사용자의 첫 진입 시 충격** — "왜 추천 종목이 없나?" 가능. D3, D6 의 명시적 안내로 완화.
- **시장 통계 영역의 데이터 의존** — KOSPI/KOSDAQ 지수, 거래대금, 시장 폭 — pykrx 일배치에 추가 데이터 (T18 task 보강).
- **모바일 시 첫 인상이 빈약** — 작은 화면에 fact 만. 그러나 단순함의 미덕.

### Neutral / Unknown
- **사용자가 "거래량 상위 종목 보고 싶다" 라는 피드백** — M1 검토 항목. ADR-0007 D5.2 의 랭킹 경계 재고.
- **시장 통계 영역의 위젯 customize** — M1+ 사용자가 영역 순서·표시 항목 customize 가능하게 할지.

## Alternatives Considered

- **A. 시장 통계 only (Watchlist 사이드바)** — 가장 중립적. 그러나 Watchlist 사용자의 첫 진입 시 본인 종목 보려면 한 번 더 클릭 → 사용성 ↓. **거부**.
- **B. 빈 캔버스 + 검색창만** — 8기둥 §2.3 극단. 신규 사용자 막막함. **거부**.
- **C. Last viewed (Stock Detail) 복원** — 편하지만 Watchlist 가 더 자연스러운 의제. **거부**.
- **D. "오늘의 시장" 영역에 거래대금 TOP 30 추가** — 사실이지만 ADR-0007 D5.2 의 랭킹 경계 위반 가능. M1 재검토. **M0 거부**.
