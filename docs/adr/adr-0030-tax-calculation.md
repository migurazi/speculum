## Context

세금 계산은 6항목 중 **법적 리스크 최고** — 자본시장법(유사투자자문)보다 직접적인 **세무사법**
영역이다. 개별 사용자 상황(보유기간·대주주 판정·손익통산)에 맞춘 세액 계산은 세무사법상
세무대리/세무상담의 무자격 영위 리스크. 또 세법은 매년 개정(대주주 양도세·금투세 등 변동
극심)이라 잘못된 세율 표시는 §2.1 Fidelity 정면 위반.

증권거래세는 매도 거래 시점의 **공개된 단순 산식**(거래금액 × 세율)이라 상황 의존이 없다.
양도소득세는 보유기간·대주주 여부·연간 손익통산 등 **개별 상황 의존**이라 세무 판단을 요한다.

## Decision

### D1. 증권거래세 계산기만 — 양도세는 자문 후 유보
M3 #5 는 **증권거래세(농어촌특별세 포함) 계산기만** 구현: 매도 종목 시장구분(코스피/코스닥/
코넥스/비상장) + 거래금액 → 세액 = 거래금액 × 세율. **양도소득세는 deferred**(D6 자문 완료 전
미구현) — 상황 의존이라 세무자문 경계.

### D2. 공개 산식 단순 적용 — 개별 상황 판단 0
세율은 **공개 법령(증권거래세법)의 시장구분별 고정 세율**을 단순 곱셈. 개별 사용자의
종합소득·대주주 판정·손익통산·보유기간 같은 **상황 의존 세무 판단 0**. 계산기는 "이 거래금액에
이 세율을 곱하면 이 금액"이라는 산술 사실만(§2.1).

### D3. 강제 디스클레이머 게이트
모든 세금 뷰에 **"본 계산은 공개 세율의 단순 참고용 적용이며 세무자문이 아닙니다. 실제 세액은
개인 상황·세법 개정에 따라 다르며 세무 전문가 상담을 요합니다."** — 디스클레이머 없이 세금 결과
렌더 차단(ADR-0007 D8.1 SourceAttribution 게이트 패턴).

### D4. 세율 효력일 freeze + 법령 출처
적용 세율마다 **효력일 + 법령 출처(증권거래세법 조항)**를 명시(§2.8 효력일 보존 패턴, ADR-0012
정신). 세율 테이블은 효력일 구간으로 버전 관리 — 과거 거래일 계산은 그 시점 세율 적용. 세율
변경은 코드 테이블 갱신(법령 출처 주석 필수).

### D5. 미확정 제도 회피
금투세 등 시행 불확실/유예 제도는 표시 안 함(잘못된 사실 = Fidelity 위반). 확정 시행 세율만.

### D6. release blocker — 세무사+변호사 자문 필수
세무사법 경계라 **세무사+변호사 자문 완료 전 release 금지**(ADR-0006 D9 변호사 자문 미실시
blocker 와 묶어 일괄 해소). 코드는 디스클레이머 게이트로 막아 구현하되, 운영 노출은 자문 후.

## Rationale
- 증권거래세 = 상황 무관 공개 산식 → 세무 판단 0 으로 세무사법 경계 안. 양도세는 유보로 회피.
- 효력일 freeze(D4)로 세율 정확성(§2.1) + 과거 거래 정합. 디스클레이머 게이트(D3)로 법적 방어.
- Portfolio(ADR-0029 D6) 와 미결합 — 거래세는 단일 거래 입력으로 독립 계산(Portfolio 없이도 가능).

## Consequences
- **Positive**: 거래 비용의 세금 부분 사실 계산. ADR-0027 백테스트 거래비용(증권거래세 bps)과 일관.
- **Negative**: 양도세 미제공(사용자 기대 일부 미충족) — 자문 후 후속. release blocker 직렬.
- **Neutral**: 세율 개정 시 코드 테이블 유지보수. 디스클레이머 상시.

## Alternatives Considered
- **A. 양도세까지 즉시 구현** — 상황 의존 세무 판단 = 세무사법 위반 리스크. 기각(D1 유보).
- **B. 디스클레이머 없이 계산기** — 세무자문 오인. 기각(D3 게이트).
- **C. Portfolio 손익과 세금 결합 자동 표시** — 세무자문 경계 진입(ADR-0029 D6). 기각 — 독립 계산기.
